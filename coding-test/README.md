# Coding Test

Coding test preparation for Systems Software / Embedded Software Engineering internships and full-time positions.

## Goal

Build solid problem-solving fundamentals and adapt them to different coding test formats.

```text
Fundamentals
    ↓
China Internship OA
    ↓
Korea Full-time Coding Tests
```

## Roadmap

### 2026.08–09 — Fundamentals

* Array / String
* Hash Table
* Two Pointer / Sliding Window
* Stack / Queue
* Binary Search
* Linked List
* Tree
* BFS / DFS
* Greedy / Basic DP

Target: 7–10 problems per week

### 2026.10 — Medium + ACM

* LeetCode Medium
* Graph / Tree
* BFS / DFS
* Heap / Priority Queue
* Backtracking
* Simulation / Implementation
* 牛客网 ACM-style problems

### 2026.11–Winter — China Internship OA

* Common Medium problems
* 牛客网 ACM problems
* Recent OA problems from target companies
* Timed practice

### After China Internship Applications — Korea

Adapt existing fundamentals to coding tests for Korean companies such as Samsung Electronics DS, SK hynix, and other Systems / Embedded positions.

## Practice Rule

```text
20–30 min independently
        ↓
Hint if needed
        ↓
Review solution if still stuck
        ↓
Understand the approach
        ↓
Reimplement the next day without references
```

The goal is not to solve as many problems as possible, but to recognize patterns and implement solutions independently.
