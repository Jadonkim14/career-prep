# LoL Event Engine V0.2 — Low-Level Event Engine

## 1. 목표

기존 **LoL Event Engine V0.1**을 기반으로, C의 **Low-Level 개념을 실제 프로그램에 적용**한다.

핵심은 새로운 게임 기능을 많이 추가하는 것이 아니라,

> **Event 데이터를 메모리·비트·바이너리 수준에서 효율적으로 표현하고, 분석 구조를 확장 가능하게 만드는 것**

이다.

---

## 2. 주요 기능

### ① Time Window Analysis(时间窗口分析)

기존의 단순한 이벤트 연속성 판단을 개선한다.

```text
DEATH ─── 12s ─── DEATH ─── 18s ─── DRAGON
│<------------- 30 sec ------------->│
```

일정 시간 범위 내의 Event들을 분석하여 **Critical Moment**를 탐지한다.

---

### ② Event Type / Flag

Event 정보를 문자열 중심에서 정수 기반으로 개선한다.

```text
Event Type
├── KILL
├── DEATH
├── DRAGON
├── BARON
└── TOWER
```

Event의 성격은 **Bit Flag(位标志)**로 표현한다.

```text
COMBAT
OBJECTIVE
MAJOR
...
```

이를 통해 하나의 Event가 여러 속성을 가질 수 있도록 한다.

---

### ③ Function Pointer 기반 Analyzer

Event 종류에 따라 적절한 분석 함수를 호출하는 구조를 만든다.

```text
Event
  ↓
Analyzer
  ├── Kill Analyzer
  ├── Objective Analyzer
  ├── Death Analyzer
  └── ...
```

새로운 Event 분석 기능을 추가하기 쉬운 구조를 목표로 한다.

---

### ④ Binary Event File

기존 Text File뿐 아니라 **Binary File(二进制文件)**로 Event 데이터를 저장하고 읽을 수 있도록 한다.

```text
Event[]
  ↓
Serialization(序列化)
  ↓
match.bin
```

그리고:

```text
match.bin
  ↓
Deserialization(反序列化)
  ↓
Event[]
```

를 지원한다.

---

### ⑤ Endianness / Memory Layout

Binary Event 데이터를 다루면서 다음을 직접 확인한다.

* Fixed-width Integer(定宽整数)
* Endianness(字节序)
* Struct Padding(结构体填充)
* Alignment(对齐)
* `sizeof`
* `offsetof`
* Pointer Casting(指针转换)

즉, **C 데이터가 실제 메모리와 파일에서 어떻게 표현되는지** 이해하는 것을 목표로 한다.

---

## 3. 기술 적용 범위

```text
C
├── Pointer / Pointer Arithmetic
├── Dynamic Memory
├── Struct
├── enum
├── Function Pointer
├── Bitwise Operation
├── Fixed-width Integer
├── Binary I/O
├── Endianness
├── Padding / Alignment
├── static / const
└── Pointer Casting
```

`volatile`, Threading, Atomic 등은 **LoL Event Engine에 억지로 적용하지 않는다.**

필요한 경우 별도 Mini Lab으로 학습한다.

---

## 4. 최종 구조

```text
             Match Data
                 ↓
        ┌────────────────┐
        │ Parser / Loader│
        └───────┬────────┘
                ↓
             Event[]
                ↓
       ┌────────┴────────┐
       ↓                 ↓
 Event Flags       Time Window
       ↓              Analysis
       └────────┬────────┘
                ↓
        Function Pointer
           Analyzer
                ↓
       Critical Moments
                ↓
             Result
```

Binary 지원:

```text
             Event[]
             ↕   ↕
       Text File / Binary File
```

---

## 5. V0.2의 핵심 결과

V0.2가 끝나면 단순한 LoL 경기 분석 프로그램이 아니라,

> **C로 구현한 확장 가능한 Event Processing Engine**

형태가 된다.

그리고 이 과정에서 **Memory, Pointer, Bitwise, Binary Data, Function Pointer, Data Layout**을 실제 코드에 적용한다.

**V0.1 = C로 Event Engine 구현**

**V0.2 = Low-Level C를 적용하여 Event Engine 발전**

이것이 최종 방향이다.
