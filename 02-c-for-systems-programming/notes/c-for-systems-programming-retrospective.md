# C for Systems Programming — 회고

## 1. 학습 목적

다음 로드맵으로 넘어가기 위한 **사전 지식 확보**.

C 자체를 완벽하게 마스터하는 것이 목표라기보다, 이후 System Programming / Linux / OS 학습을 위한 기본적인 구조를 잡는 것이 목적이었다.

---

## 2. 학습 결과

C의 전체적인 **구조와 주요 개념의 틀은 어느 정도 잡혔다.**

다만 각 개념을 완전히 깊게 이해했다기보다는,

> "이런 개념이 있고, 대략 이런 식으로 동작한다."

정도의 이해가 현재 수준이다.

---

## 3. 얻은 것

- C 문법에 대한 거부감 감소
- Pointer / Memory에 대한 기본적인 감각
- 프로그램의 구조와 컴파일 / 링크 과정에 대한 이해

- 직접 프로그램을 구현해본 경험

---

## 4. 부족한 점

### 개념 간 연결

C의 여러 개념이 **전체적으로 어떻게 연결되는지** 아직 명확하지 않다.

### 실무 적용

배운 C 개념을 **취업 후 실제 업무에서 어떻게 사용하는지**에 대한 감각이 부족하다.

현재는 개념을 배운 것과 실제 시스템 소프트웨어 개발 사이에 간극이 있다.
